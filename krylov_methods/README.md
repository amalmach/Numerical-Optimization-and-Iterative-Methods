# Krylov Subspace Methods

Numerical implementations of Krylov subspace algorithms for solving linear
systems, constructing orthogonal bases, and exploring spectral properties.

Includes modular solvers, shared preconditioners, regression tests against
SciPy, reproducible examples, and interactive Jupyter notebooks.

</div>

---

## Main idea

Krylov subspace methods solve large linear systems by building approximate
solutions in subspaces generated by repeated applications of a matrix or
linear operator. Consider

<p align="center">
$\displaystyle Ax=b,$
</p>

where $A\in\mathbb{F}^{n\times n}$, $b\in\mathbb{F}^{n}$, and
$\mathbb{F}=\mathbb{R}$ or $\mathbb{C}$.

Starting from $x_0$, the initial residual is

<p align="center">
$\displaystyle r_0=b-Ax_0.$
</p>

The Krylov subspace of dimension $m$ is

<p align="center">
$\displaystyle \mathcal K_m(A,r_0)=
\mathrm{span}\{r_0,Ar_0,A^2r_0,\ldots,A^{m-1}r_0\}.$
</p>

Different algorithms choose different bases, projection conditions, and
recurrences. Their properties depend on the structure of $A$.

The solver implementations generally report convergence against the **true
residual** using

<p align="center">
$\displaystyle \|b-Ax_k\|_2\leq
\max\bigl(\mathrm{atol},\mathrm{rtol}\,\|b\|_2\bigr).$
</p>

For complex systems, transpose products in the relevant mathematical
formulations become conjugate-transpose (Hermitian) products.

## Implemented methods

| Method | Main purpose | Solver package | Mathematical description |
|:---|:---|:---|:---|
| **Conjugate Gradient (CG/PCG)** | Short-recurrence solver for symmetric / Hermitian positive-definite systems | [CG](conjugate_gradient_solver/ConjugateGradient.py) | [Formulation](conjugate_gradient_solver/README.md) |
| **GMRES** | Residual-minimizing solver for general nonsymmetric systems; restarted and unrestarted variants | [GMRES](gmres_solver/GMRES.py) | [Formulation](gmres_solver/README.md) |
| **BiCGSTAB** | Short-recurrence stabilized solver for general nonsymmetric systems | [BiCGSTAB](bicgstab_solver/BiCGSTAB.py) | [Formulation](bicgstab_solver/README.md) |
| **Symmetric Lanczos** | Orthonormal basis construction, tridiagonalization, Ritz values, and optional Galerkin approximation | [Lanczos](symmetric_lanczos_solver/Lanczos.py) | [Formulation](symmetric_lanczos_solver/README.md) |
| **Shared preconditioning** | Jacobi, LU, ILU, Cholesky, IC(0), SSOR, and custom inverse actions | [Preconditioning methods](preconditioners/preconditioners.py) | [Theory and use](preconditioners/README.md) |

**Steepest Descent** is a gradient-based baseline and lives in the separate
[`gradient_methods/steepest_descent_solver`](../gradient_methods/steepest_descent_solver/README.md)
package. It is included in the comparison notebook alongside the Krylov methods.

### Method selection

- **Real SPD / complex Hermitian PD:** CG is a natural first choice; the
  classical steepest-descent iteration provides an instructive comparison.
- **General nonsymmetric:** GMRES or BiCGSTAB. Restarted GMRES controls the
  size of the stored Krylov basis; BiCGSTAB uses short recurrences.
- **Symmetric / Hermitian eigenvalue problems:** Lanczos provides a small
  tridiagonal projection whose eigenvalues are Ritz approximations.
  Its optional Galerkin solver should not be confused with a robust
  general symmetric-indefinite solver such as MINRES.

> **Notation: Throughout this documentation, SPD refers to real symmetric
> positive-definite matrices, and PD to positive-definite matrices.

## Preconditioning

Preconditioning aims to improve convergence by applying an approximation to
$A^{-1}$ without forming that inverse explicitly. The shared
[`preconditioners/`](preconditioners/README.md) package supplies the available
inverse actions and their mathematical and numerical descriptions.

Preconditioning is integrated differently in each algorithm:

- **CG:** fixed symmetric / Hermitian positive-definite inverse action.
- **GMRES:** the implementation uses **left preconditioning**, so its
  internal least-squares estimate is a preconditioned residual; convergence
  is checked against the original true residual.
- **BiCGSTAB:** the implementation uses **right preconditioning** and checks
  the original true residual.

Preconditioner names and options are listed in each solver's README.
Not every preconditioner is appropriate for every algorithm; for example,
generic nonsymmetric ILU is not a valid PCG preconditioner.

### Numerical questions explored

1. **SPD and complex Hermitian PD systems:** How do Steepest Descent, CG,
   GMRES, and BiCGSTAB compare in iteration count, residual, error, and time?
2. **Nonsymmetric systems:** What changes when GMRES is restarted, and how
   does its convergence compare with BiCGSTAB?
3. **Lanczos:** How accurate are the Ritz values and the tridiagonal
   projection? When does the Galerkin approximation solve the linear system?
4. **Preconditioning:** How do different inverse actions change convergence
   without changing the exact solution?

From the **repository root**, install the dependencies:

```bash
python3 -m pip install numpy scipy matplotlib ipywidgets ipykernel jupyterlab
```

Launch interactive notebooks:

```bash
jupyter lab
```

Run the regression tests:

```bash
python3 -m unittest krylov_methods.conjugate_gradient_solver.test_conjugate_gradient -v
python3 -m unittest krylov_methods.gmres_solver.test_gmres -v
python3 -m unittest krylov_methods.bicgstab_solver.test_bicgstab -v
python3 -m unittest krylov_methods.symmetric_lanczos_solver.test_lanczos -v
python3 -m unittest krylov_methods.preconditioners.test_preconditioners -v
```

Run individual examples:

```bash
python3 -m krylov_methods.conjugate_gradient_solver.example
python3 -m krylov_methods.gmres_solver.example
python3 -m krylov_methods.bicgstab_solver.example
python3 -m krylov_methods.symmetric_lanczos_solver.example
```

```bash

python3 -m gradient_methods.steepest_descent_solver.example
```

## Numerical considerations

- The **true residual** and the **solution error** are different quantities;
  ill-conditioning can make a small residual misleading.
- Classical full GMRES stores an expanding Krylov basis; restarting limits
  memory but can slow convergence or cause stagnation.
- BiCGSTAB residual convergence may be nonmonotonic; numerical breakdown is
  possible.
- Lanczos may lose orthogonality in finite precision; reorthogonalization
  improves stability at an additional storage and computation cost.
- Sparse and matrix-free support is available, but some educational
  preconditioners use dense intermediate storage and are not intended
  for large-scale sparse production problems.
