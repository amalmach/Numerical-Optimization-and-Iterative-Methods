# Generalized Minimal Residual (GMRES)

The **Generalized Minimal Residual method (GMRES)** is a Krylov
subspace iterative method for solving large, sparse, and generally
nonsymmetric linear systems.

GMRES constructs an orthonormal basis using the Arnoldi process
and minimizes the Euclidean norm of the residual over successive
Krylov subspaces.

This document presents the mathematical foundations, numerical
algorithms, restarted variants, and preconditioning techniques.

---

## Mathematical Foundations

<details>
<summary><strong>1. Krylov Subspace</strong></summary>

<br>

Consider the linear system

```math
Ax=b,
```

where $A\in\mathbb{R}^{n\times n}$ and $b\in\mathbb{R}^n$.

Given an initial approximation $x_0$, the initial residual is

```math
r_0=b-Ax_0.
```

The Krylov subspace of dimension $m$ is

```math
\mathcal{K}_m(A,r_0)
=
\mathrm{span}
\left\{
r_0,Ar_0,A^2r_0,\ldots,A^{m-1}r_0
\right\}.
```

GMRES seeks an approximation

```math
x_m\in x_0+\mathcal{K}_m(A,r_0)
```

that minimizes the Euclidean residual norm:

```math
\|b-Ax_m\|_2
=
\min_{x\in x_0+\mathcal{K}_m(A,r_0)}
\|b-Ax\|_2.
```

</details>

---

<details>
<summary><strong>2. Arnoldi Process</strong></summary>

<br>

The Arnoldi process constructs an orthonormal basis of the
Krylov subspace.

**Initialization**

```math
\beta=\|r_0\|_2,
\qquad
v_1=\frac{r_0}{\beta}.
```

For each iteration $k=1,\ldots,m$:

1. Compute the matrix-vector product:

   ```math
   w=Av_k.
   ```

2. Orthogonalize against the previous Arnoldi vectors:

   ```math
   h_{i,k}=v_i^Tw,
   \qquad i=1,\ldots,k.
   ```

   ```math
   w=w-h_{i,k}v_i.
   ```

3. Compute the normalization coefficient:

   ```math
   h_{k+1,k}=\|w\|_2.
   ```

4. If $h_{k+1,k}\neq0$, construct:

   ```math
   v_{k+1}=\frac{w}{h_{k+1,k}}.
   ```

The resulting basis satisfies

```math
V_m^TV_m=I_m.
```

</details>

---

<details>
<summary><strong>3. Hessenberg Matrix</strong></summary>

<br>

The Arnoldi process generates an upper Hessenberg matrix

```math
\overline{H}_m
\in\mathbb{R}^{(m+1)\times m}.
```

Its entries satisfy

```math
h_{i,k}=0
\qquad \text{for }i>k+1.
```

The Arnoldi factorization is

```math
AV_m=V_{m+1}\overline{H}_m.
```

Equivalently,

```math
AV_m
=
V_mH_m
+
h_{m+1,m}v_{m+1}e_m^T.
```

Using the orthogonality of $V_m$, we obtain

```math
V_m^TAV_m=H_m.
```

The matrix $H_m$ therefore represents the projection
of $A$ onto the Krylov subspace.

</details>

---

<details>
<summary><strong>4. Least-Squares Problem</strong></summary>

<br>

The approximate solution is expressed as

```math
x_m=x_0+V_my_m.
```

The corresponding residual is

```math
r_m
=
b-Ax_m
=
r_0-AV_my_m.
```

Using the Arnoldi factorization,

```math
r_m
=
V_{m+1}
\left(
\beta e_1-\overline{H}_my_m
\right).
```

Since $V_{m+1}$ has orthonormal columns,

```math
\|r_m\|_2
=
\left\|
\beta e_1-\overline{H}_my_m
\right\|_2.
```

Thus, the GMRES minimization problem reduces to

```math
y_m
=
\underset{y\in\mathbb{R}^m}
{\mathrm{arg\,min}}
\left\|
\beta e_1-\overline{H}_my
\right\|_2.
```

This reduced least-squares problem can be solved efficiently
using Givens rotations.

</details>

---

<details>
<summary><strong>5. Givens Rotations</strong></summary>

<br>

Givens rotations are used to transform the upper Hessenberg
matrix into an upper-triangular matrix.

For a real-valued problem, the rotation acting on two
consecutive rows is

```math
G_k=
\begin{pmatrix}
c_k & s_k\\
-s_k & c_k
\end{pmatrix},
```

where

```math
c_k^2+s_k^2=1.
```

The rotation coefficients are computed from the
current Hessenberg entries:

```math
\delta_k
=
\sqrt{h_{k,k}^2+h_{k+1,k}^2}.
```

For $\delta_k\neq0$,

```math
c_k=\frac{h_{k,k}}{\delta_k},
\qquad
s_k=\frac{h_{k+1,k}}{\delta_k}.
```

Applying successive rotations gives

```math
Q_m\overline{H}_m
=
\begin{pmatrix}
R_m\\
0
\end{pmatrix},
```

where $R_m$ is upper triangular.

The transformed right-hand side is

```math
g=Q_m(\beta e_1).
```

The reduced problem becomes

```math
R_my_m=g_{1:m}.
```

The coefficient vector $y_m$ can then be obtained
through backward substitution.

The residual norm is

```math
\|r_m\|_2=|g_{m+1}|.
```

</details>

## GMRES Algorithms

<details>
<summary><strong>6. Unrestarted GMRES (Without Preconditioning)</strong></summary>

<br>

**Input:** Matrix $A$, vector $b$, initial guess $x_0$,
tolerance $\varepsilon$, maximum iterations $N$.

**Initialization**

1. Compute

   ```math
   r_0=b-Ax_0,
   \qquad
   \beta=\|r_0\|_2.
   ```

2. If $\beta\leq\varepsilon$, return $x_0$.

3. Initialize

   ```math
   v_1=\frac{r_0}{\beta},
   \qquad
   g=\beta e_1.
   ```

**Iterative process**

4. **For** $k=1,\ldots,N$:

   - Compute $w=Av_k$.
   - Apply Arnoldi orthogonalization.
   - Extend the Hessenberg matrix.
   - Construct the next Arnoldi vector, if possible.
   - Apply previously computed Givens rotations.
   - Construct and apply the new Givens rotation.
   - Update the transformed right-hand side.
   - Compute the residual estimate:

     ```math
     \rho_k=|g_{k+1}|.
     ```

   - If $\rho_k\leq\varepsilon$, stop.

   - If the Arnoldi process terminates, solve the
     current reduced problem and check convergence.

5. **End For**

**Solution reconstruction**

6. Solve the upper-triangular system:

   ```math
   R_my_m=g_{1:m}.
   ```

7. Compute the approximate solution:

   ```math
   x_m=x_0+V_my_m.
   ```

8. Return the approximate solution and convergence history.

**Remark:** Unrestarted GMRES allows the Krylov basis to
grow throughout the iterations, increasing memory requirements
and orthogonalization costs.

</details>

---

<details>
<summary><strong>7. Restarted GMRES(m) (Without Preconditioning)</strong></summary>

<br>

Restarted GMRES limits the dimension of the Krylov subspace
to a prescribed restart parameter $m$.

After at most $m$ Arnoldi iterations, the approximate
solution is updated and a new Krylov cycle begins.

**Input:** Matrix $A$, vector $b$, initial approximation $x_0$,
tolerance $\varepsilon$, restart parameter $m$, and
maximum total iterations $N$.

**Algorithm**

1. Initialize $x=x_0$.

2. **While** the convergence criterion is not satisfied
   and the iteration budget has not been exhausted:

   - Compute the residual:

     ```math
     r=b-Ax.
     ```

   - Compute

     ```math
     \beta=\|r\|_2.
     ```

   - If $\beta\leq\varepsilon$, stop.

   - Initialize the Arnoldi basis:

     ```math
     v_1=\frac{r}{\beta}.
     ```

   - Perform at most $m$ Arnoldi iterations.

   - Construct and update the Hessenberg matrix.

   - Apply Givens rotations to the reduced
     least-squares problem.

   - Stop the current cycle early if convergence
     or Arnoldi termination occurs.

   - Solve

     ```math
     R_jy_j=g_{1:j},
     ```

     where $j\leq m$ is the number of iterations
     completed in the current cycle.

   - Update the approximate solution:

     ```math
     x\leftarrow x+V_jy_j.
     ```

   - Recompute the residual for the next cycle.

3. **End While**

4. Return the approximate solution and convergence history.

**Remark:** Restarting reduces storage requirements,
but convergence may stagnate when the restart dimension
is too small.

</details>

## Preconditioning

<details>
<summary><strong>8. Preconditioning Techniques</strong></summary>

<br>

Preconditioning aims to improve the convergence of GMRES
by transforming the original linear system into an
equivalent system with more favorable numerical properties.

A preconditioner $M$ approximates $A$ while remaining
significantly cheaper to invert or apply.

**Left preconditioning**

```math
M^{-1}Ax=M^{-1}b.
```

The corresponding residual is

```math
\widetilde{r}=M^{-1}(b-Ax).
```

Left-preconditioned GMRES minimizes

```math
\|M^{-1}(b-Ax)\|_2.
```

**Right preconditioning**

```math
AM^{-1}y=b,
\qquad
x=M^{-1}y.
```

Right-preconditioned GMRES can minimize the
original residual norm directly.

**Split preconditioning**

```math
M_L^{-1}AM_R^{-1}y=M_L^{-1}b,
```

with

```math
x=M_R^{-1}y.
```

**Common preconditioners**

- Incomplete LU factorization (ILU).
- Incomplete Cholesky factorization (IC).
- Sparse Approximate Inverse (SPAI).
- Factorized Sparse Approximate Inverse (FSAI).
- Geometric Multigrid (GMG).
- Algebraic Multigrid (AMG).
- Domain decomposition methods.

</details>

<details>
<summary><strong>9. Restarted Preconditioned GMRES</strong></summary>

<br>

This algorithm combines restarted GMRES with left
preconditioning, following the formulation developed
in the thesis.

**Input:** Matrix $A$, vector $b$, initial guess $x_0$,
preconditioner $M$, tolerance $\varepsilon$,
restart parameter $m$, and maximum total iterations $N$.

**Initialization**

1. Set $x=x_0$.

2. Initialize the convergence status and residual history.

**Outer iteration**

3. **While** convergence has not been achieved
   and the iteration budget remains available:

   **Step 1 — Compute the preconditioned residual**

   ```math
   r=M^{-1}(b-Ax).
   ```

   **Step 2 — Compute its norm**

   ```math
   \beta=\|r\|_2.
   ```

   If $\beta\leq\varepsilon$, stop.

   **Step 3 — Initialize the Arnoldi basis**

   ```math
   v_1=\frac{r}{\beta},
   \qquad
   g=\beta e_1.
   ```

   **Step 4 — Arnoldi iterations**

   **For** $k=1,\ldots,m$:

   - Compute the preconditioned matrix-vector product:

     ```math
     w=M^{-1}Av_k.
     ```

   - Orthogonalize $w$ against $v_1,\ldots,v_k$.

   - Compute the Hessenberg coefficients:

     ```math
     h_{i,k}=v_i^Tw.
     ```

   - Update the orthogonal component:

     ```math
     w=w-h_{i,k}v_i.
     ```

   - Normalize the new Arnoldi vector when possible.

   - Apply the previous Givens rotations.

   - Compute and apply the new Givens rotation.

   - Update the transformed right-hand side.

   - Estimate the preconditioned residual norm:

     ```math
     \rho_k=|g_{k+1}|.
     ```

   - If $\rho_k\leq\varepsilon$, stop the inner iteration.

   - If Arnoldi terminates, solve the reduced problem
     and check whether convergence has been achieved.

   **End For**

   **Step 5 — Solve the reduced problem**

   Let $j\leq m$ be the number of completed
   Arnoldi iterations.

   Solve

   ```math
   R_jy_j=g_{1:j}.
   ```

   **Step 6 — Update the approximation**

   ```math
   x\leftarrow x+V_jy_j.
   ```

   **Step 7 — Check convergence**

   Recompute

   ```math
   r=M^{-1}(b-Ax).
   ```

   Check whether

   ```math
   \|r\|_2\leq\varepsilon.
   ```

   The true residual $\|b-Ax\|_2$ may also be
   monitored separately.

4. **End While**

5. Return the approximate solution, residual history,
   iteration count, and convergence status.

**Remark:** The preconditioner should be applied through
linear solves involving $M$, rather than by explicitly
constructing $M^{-1}$.

</details>

## Numerical Analysis

<details>
<summary><strong>10. Numerical Properties</strong></summary>

<br>

**Convergence**

GMRES minimizes the Euclidean residual norm over the
current affine Krylov subspace.

In exact arithmetic, unrestarted GMRES produces
nonincreasing residual norms.

**Computational complexity**

At iteration $k$, Arnoldi orthogonalization requires
inner products and vector updates involving the
previously generated basis vectors.

The total orthogonalization cost increases with
the Krylov dimension.

**Memory requirements**

Unrestarted GMRES stores an expanding orthonormal basis.

Restarted GMRES(m) limits the number of stored basis
vectors to approximately $m+1$.

**Numerical stability**

Loss of orthogonality can affect the accuracy of
the Arnoldi decomposition and residual estimates.

Modified Gram-Schmidt and reorthogonalization
may improve numerical stability.

**Restarting**

Restarting controls memory usage and computational cost,
but may slow convergence or cause stagnation.

**Preconditioning**

An effective preconditioner can substantially reduce
the number of iterations required for convergence.

**Finite-precision arithmetic**

In floating-point arithmetic, explicitly computed
residual norms may differ from the residual estimates
obtained using Givens rotations.

Periodic residual recomputation can help assess
the accuracy of the approximation.

</details>
