# Numerical Optimization and Iterative Methods

### Numerical Optimization | Krylov Methods | Nonlinear Solvers

Python implementations and computational experiments exploring numerical optimization, iterative algorithms, and scientific computing.

This repository provides educational and research-oriented implementations of numerical methods for solving linear systems, nonlinear equations, and optimization problems.

The project combines Python scripts and Jupyter notebooks to illustrate algorithmic principles, numerical convergence, and practical applications.
